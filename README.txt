DOWNLY WEBSITE
==============

Files:
- index.html: landing page
- style.css: responsive dark + lime design
- script.js: small page script
- downly-icon.svg: simple matching icon

IMPORTANT — ENABLE THE APK DOWNLOAD
1. Put your real Android APK in this folder.
2. Rename it exactly: Downly.apk
3. Upload all files together to your web host.
4. Test the "تحميل Downly" button from the published website.

The download buttons already point to ./Downly.apk. The APK itself was not included
because it was not provided with the request.

You can test the page locally by opening index.html in a browser. For a public website,
upload the folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.
