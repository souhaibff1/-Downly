GITHUB RELEASES APK DOWNLOAD
----------------------------
The website download buttons point to:
https://github.com/souhaibff1/downly/releases/latest/download/Downly.apk

To publish a new app version:
1. Open the GitHub repository: https://github.com/souhaibff1/downly
2. Create a new Release (or edit/create a release).
3. Attach the APK file and name it exactly Downly.apk.
4. Publish the release.
5. The website will download the APK from the latest published release automatically.
6. If you update the website files, upload the changed index.html to the website repository and commit it.

IMPORTANT:
- The repository name and owner in the download URL must match your actual GitHub repository.
- The uploaded release asset filename must be exactly Downly.apk (including capitalization).
- The website ZIP does not contain the APK itself.
