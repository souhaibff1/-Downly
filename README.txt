DOWNLY WEBSITE
==============

The download buttons now use your exact GitHub Release URL:
https://github.com/souhaibff1/-Downly/releases/download/v1.0.0/Downly.apk

To update the website:
1. Download and extract this ZIP.
2. Upload the updated website files to the GitHub repository used for GitHub Pages.
3. Commit the changes.

This link is fixed to release v1.0.0. When you publish a future version, update the URL in index.html to that release's exact URL, or switch to a latest-release URL if the asset filename remains Downly.apk.

Make sure the GitHub repository and release are public for visitors to download without signing in.
